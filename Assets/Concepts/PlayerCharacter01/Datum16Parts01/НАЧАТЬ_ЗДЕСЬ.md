# Начать здесь: Datum 16 для Meshy 7.1 Ultra 4K

Твой выбранный процесс: **одна картинка → одна генерация в Ultra 4K; Multi-View выключен**.

## Что открыть

- [Галерея с русскими подписями](index.html) — посмотреть все детали и открыть нужный PNG.
- **01_Для_Meshy_4K** — 13 основных картинок для загрузки в Meshy.
- **02_Справочные_виды_Blender** — 3 дополнительных изображения для проверки при моделировании.
- **03_Технические_данные** — история, промпты, контрольные суммы и архив прежних имён.

## Как использовать основные файлы

1. Открой папку **01_Для_Meshy_4K**.
2. Выбери один PNG и загрузи его как единственное изображение.
3. Выбери Meshy 7.1 и режим геометрии **Ultra 4K**. **Multi-View оставь выключенным.**
4. Проверь полученную форму со всех сторон. Текстуры добавляй выбранному удачному результату.
5. Скачай модель в **GLB** для Blender. Сохраняй номер и название детали в имени скачанной модели, чтобы сопоставить её с картинкой.

Один PNG — одна деталь или одна сборка. Номер — идентификатор, а не обязательный порядок работы. Для вида от первого лица удобно начать с **08 — перчатки** и **07 — наруча**.

## Что означает 4K

Режим **Ultra 4K** выбирается в Meshy для генерации геометрии. Подготовленные входные изображения по-прежнему имеют размер **1254 × 1254 пикселя**; переименование не увеличивает их разрешение. Разрешение текстур выбирается отдельно.

Из одного изображения Meshy восстанавливает невидимую сторону предположительно. При сборке сверяй её со справочными видами и исходными артами. Жёсткие пластины живота, локтей и коленей должны сохранять нужную подвижность относительно соседних деталей.
