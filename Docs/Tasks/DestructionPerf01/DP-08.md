## Outcome

Bound scene-wide cost before damage and after settling, using the DP-06 lifecycle
as the gameplay contract. Adopt representation/reuse changes only where measured.

## Bounded work

- Consider Chaos Debris Optimizer collision proxies using
  [the installed-plugin findings](../ChaosDebrisOptimizer01.md). They do not supply
  a shared render representation or prove physical/bullet collision equivalence;
  measure their creation/steady-state cost within DP-06's lifecycle contract.
- Measure repeated intact assets and settled rubble for CPU, Render/GPU, memory,
  actor/component count and collision/query cost at representative density.
- Evaluate installed-engine instanced/root proxies and local activation if they
  reduce intact-scene overhead while preserving bullet/damage discovery.
- Measure rendering/collision cost of DP-06 settled representations. Evaluate
  Nanite, material slots, shadows and dust overdraw only for identified limits;
  avoid reauthoring accepted architecture or reopening visual design.
- Consider bounded pools only if construction/allocation costs warrant them.
  Reset physics, collision, materials, IDs/generations, delegates, timers/latent
  work and effect ownership before reuse. Define memory bounds and a correct
  capacity-exhaustion behavior that preserves gameplay-important destruction.
- Document intact -> active -> settled -> reactivated/reset transitions, using
  DP-06's rules for retained blocking, retirement and wakeup. DP-04 owns effect
  component pooling; do not create a second independent presentation lifecycle.

## Acceptance and focused verification

- Adopted transitions show repeatable measured benefit, preserve visible damage
  and required collision, and introduce no disruptive visible pop or stale hits.
- Repeated activation/reset/reuse and world teardown stabilize memory and actor/
  component counts; delayed work cannot reach a recycled identity.
- Test immediate shots/damage after activation or reuse and interaction with the
  settled representation. Pool exhaustion remains correct and is measured.
- State source/derived-asset and cache footprint. If proxies/pooling do not help,
  retain the current representation with evidence rather than forcing a redesign.

## Handoff and limits

Record the scene-representation contract, adopted options and cost curves here;
store raw evidence under `Saved/DestructionPerf01/DP-08/`. Preserve DP-06's physics
lifecycle ownership. This task does not approve a different lobby layout, collision
that disagrees with visible cover, or an unbounded reserve of pooled objects.
